# JW Meetings App v1.0.1

Personal study aid - EN/TL toggle.

## How to install
1. Enable GitHub Pages (Settings > Pages > Branch: main / root)
2. Open the Pages URL on your phone
3. Android: Chrome menu > Add to Home Screen / Install App
4. iPhone: Share button > Add to Home Screen

## Files
- index.html - main app
- manifest.json - PWA config
- sw.js - offline support
- apple-touch-icon.png - icon (optional, add your own)
